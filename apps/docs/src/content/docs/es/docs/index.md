description: Guías de ArtisanForm, la librería React para formularios multi-paso (wizards) declarativos con un esquema serializable en JSON.
---

ArtisanForm construye formularios multi-paso (wizards) en React a partir de un esquema declarativo serializable en JSON, con inputs listos para usar, validación (React Hook Form + Yup) y kits de UI intercambiables.

- [Schema v1](/es/docs/schema-v1/): el contrato público.
- [Extensión de UI](/es/docs/ui/): `components`, `classNames`, `unstyled` y kits de UI.
