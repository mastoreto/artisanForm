ArtisanForm convierte un esquema declarativo y serializable en JSON en un formulario multi-paso (wizard) funcional en React, con validación, borradores y kits de UI intercambiables.

<Aside type="caution" title="Beta">
ArtisanForm es una beta 0.x y todavía no está publicada en ningún registro. Hasta la primera publicación, sigue el [repositorio](https://github.com/mastoreto/artisanForm) para instalarla desde el código fuente.
</Aside>

## Tu primer wizard

<Steps>

1. **Instalá** la librería y sus peers de formulario (funciona con el React que ya tenés, 18.3.1 o superior, incluido 19).

   <Tabs syncKey="pm">
     <TabItem label="npm">
     ```bash
     npm install artisanform@beta react-hook-form yup zustand
     ```
     </TabItem>
     <TabItem label="pnpm">
     ```bash
     pnpm add artisanform@beta react-hook-form yup zustand
     ```
     </TabItem>
     <TabItem label="yarn">
     ```bash
     yarn add artisanform@beta react-hook-form yup zustand
     ```
     </TabItem>
     <TabItem label="bun">
     ```bash
     bun add artisanform@beta react-hook-form yup zustand
     ```
     </TabItem>
   </Tabs>

2. **Describe el formulario** con `defineForm`: una lista de pasos, cada uno con campos tipados.

3. **Renderízalo** con `<ArtisanForm>`. `onSubmit` recibe los valores ya validados.

   ```tsx
   import { ArtisanForm, defineForm } from 'artisanform';
   import 'artisanform/style.css';

   const form = defineForm({
     schemaVersion: 1,
     id: 'contact',
     steps: [
       {
         id: 'main',
         type: 'form',
         title: 'Contacto',
         fields: [
           { name: 'email', type: 'email', label: 'Email', required: true },
         ],
       },
     ],
   });

   export default function ContactPage() {
     return (
       <ArtisanForm scheme={form} onSubmit={(values) => console.log(values)} />
     );
   }
   ```

</Steps>
