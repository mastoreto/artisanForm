---
title: ArtisanForm
description: Formularios multi-paso (wizards) declarativos para React.
---

Librería React para formularios multi-paso (wizards) construidos desde un esquema JSON serializable: más de 30 tipos de campo, pagos, subida de archivos y kits de UI tematizables.

```bash
npm install artisanform@beta react react-dom react-hook-form yup zustand
```

## Guías

- [Schema v1](schema-v1/): el contrato de esquema serializable y versionado.
- [Extensión de UI y kits](ui/): estilos, `components`, `classNames` y los kits oficiales.
- [Pagos](payments/): plugins, el principio de seguridad y una checklist de producción.
- [Archivos y storage](files/): campos `file` e `image` y adaptadores de storage.
- [Accesibilidad y entornos](accessibility/): qué viene incluido, qué se verifica, navegadores y versiones probados.
- [Release](releasing/): cómo se publican los cinco paquetes en npm.

Los componentes, sus estados y controles están en [Storybook](https://mastoreto.github.io/artisanForm/storybook/). El código y el seguimiento de issues están en [GitHub](https://github.com/mastoreto/artisanForm).
