title: Documentation
description: Guides for ArtisanForm, the React library for declarative multi-step forms (wizards) with a JSON-serializable schema.
---

ArtisanForm builds multi-step forms (wizards) in React from a declarative, JSON-serializable schema, with ready-made inputs, validation (React Hook Form + Yup) and pluggable UI kits.

- [Schema v1](/docs/schema-v1/): the public contract.
- [UI extension](/docs/ui/): `components`, `classNames`, `unstyled` and UI kits.
