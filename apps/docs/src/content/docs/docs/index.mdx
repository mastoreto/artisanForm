ArtisanForm turns a declarative, JSON-serializable schema into a working multi-step form (wizard) in React, with validation, drafts and swappable UI kits.

<Aside type="caution" title="Beta">
ArtisanForm is a 0.x beta and is not published to a registry yet. Until the first publish, follow the [repository](https://github.com/mastoreto/artisanForm) for installing from source.
</Aside>

## Your first wizard

<Steps>

1. **Install** the library and its peers (React 18.3.1 or later, including 19).

   ```bash
   npm install artisanform react react-dom react-hook-form yup zustand
   ```

2. **Describe the form** with `defineForm`: a list of steps, each with typed fields.

3. **Render it** with `<ArtisanForm>`. `onSubmit` receives the validated values.

   ```tsx
   import { ArtisanForm, defineForm } from 'artisanform';
   import 'artisanform/style.css';

   const form = defineForm({
     schemaVersion: 1,
     id: 'contact',
     steps: [
       {
         id: 'main',
         type: 'form',
         title: 'Contact',
         fields: [
           { name: 'email', type: 'email', label: 'Email', required: true },
         ],
       },
     ],
   });

   export default function ContactPage() {
     return (
       <ArtisanForm scheme={form} onSubmit={(values) => console.log(values)} />
     );
   }
   ```

</Steps>
