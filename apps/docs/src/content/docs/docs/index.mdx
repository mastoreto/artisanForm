ArtisanForm turns a declarative, JSON-serializable schema into a working multi-step form (wizard) in React, with validation, drafts and swappable UI kits.

<Aside type="caution" title="Release candidate">
ArtisanForm `1.0.0-rc.3` is on npm as `latest`, so a plain `npm install artisanform` installs it. The v1 contract is frozen for 1.x; the stable `1.0.0` follows after a period without contract changes.
</Aside>

## Your first wizard

<Steps>

1. **Install** the library and its form peers (it works with the React you already have, 18.3.1 or later, including 19).

   <Tabs syncKey="pm">
     <TabItem label="npm">
     ```bash
     npm install artisanform react-hook-form yup zustand
     ```
     </TabItem>
     <TabItem label="pnpm">
     ```bash
     pnpm add artisanform react-hook-form yup zustand
     ```
     </TabItem>
     <TabItem label="yarn">
     ```bash
     yarn add artisanform react-hook-form yup zustand
     ```
     </TabItem>
     <TabItem label="bun">
     ```bash
     bun add artisanform react-hook-form yup zustand
     ```
     </TabItem>
   </Tabs>

2. **Describe the form** with `defineForm`: a list of steps, each with typed fields.

3. **Render it** with `<ArtisanForm>`. `onSubmit` receives the validated values.

   ```tsx
   import { ArtisanForm, defineForm } from 'artisanform';
   import 'artisanform/style.css';

   const form = defineForm({
     schemaVersion: 1,
     id: 'contact',
     steps: [
       {
         id: 'main',
         type: 'form',
         title: 'Contact',
         fields: [
           { name: 'email', type: 'email', label: 'Email', required: true },
         ],
       },
     ],
   });

   export default function ContactPage() {
     return (
       <ArtisanForm scheme={form} onSubmit={(values) => console.log(values)} />
     );
   }
   ```

</Steps>
