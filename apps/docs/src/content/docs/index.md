---

React library for multi-step forms (wizards) built from a serializable JSON schema: 30+ field types, payments, file uploads and themeable UI kits.

```bash
npm install artisanform@beta react react-dom react-hook-form yup zustand
```

## Guides

- [Schema v1](schema-v1/): the serializable, versioned schema contract.
- [UI extension and kits](ui/): styles, `components`, `classNames` and the official kits.
- [Payments](payments/): plugins, the security principle and a production checklist.
- [Files and storage](files/): `file` and `image` fields and storage adapters.
- [Accessibility and environments](accessibility/): what is built in, what is checked, tested browsers and versions.
- [Releasing](releasing/): how the five packages are published to npm.

The source and the issue tracker are on [GitHub](https://github.com/mastoreto/artisanForm).
